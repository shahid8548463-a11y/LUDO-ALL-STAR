# LUDO STAR — Offline prototype

This is a Flutter starter project for an offline Ludo game with 2/3/4 player modes and computer turns.

## Run
1. Install Flutter.
2. In this folder run: `flutter pub get`
3. Connect an Android phone/emulator.
4. Run: `flutter run`
5. For an APK: `flutter build apk --release`

Note: This is a first playable prototype. The board/rules/AI can be expanded in the next version.
